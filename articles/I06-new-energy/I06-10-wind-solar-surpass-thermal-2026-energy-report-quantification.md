# 风光装机历史性超越火电：2026能源产业生态报告深度量化分析与A股新能源投资策略

## 一、核心摘要

2026年7月25日，中国企业改革与发展研究会正式发布《2026能源产业生态报告》，揭示了中国能源转型的一座历史性里程碑：**"十四五"期间，我国风电光伏累计装机从5.3亿千瓦增至18.4亿千瓦，增长超2倍，历史性超越火电装机，跃居电力系统第一大电源。** 同时，核电运行装机总量稳居全球第一，生物质能发电装机连续7年规模全球第一。2025年全国能源重点项目投资额首超3.5万亿元，同比增长近11%。

本报告基于"双引擎四层融合模型"，从**装机结构变迁、产业链量化分析、历史规律复盘、板块轮动评估、十五五规划展望、标的五维评分**六大维度，对这一标志性事件进行深度量化分析。核心结论：**风光装机超越火电标志着中国能源结构从"增量补充"正式迈入"规模化替代"阶段，十五五期间可再生能源投资将超5万亿元，2030年风光装机占比将超50%。A股新能源赛道长期利好，但短期需警惕火电板块的估值重估风险与新能源产能过剩压力。**

| 核心指标 | 量化数据 |
|---------|---------|
| 2025年风光累计装机 | 18.4亿千瓦（占总装机47.3%） |
| 2020年风光累计装机 | 5.3亿千瓦 |
| 五年装机增幅 | +247%（CAGR 28.3%） |
| 2025年能源投资 | 3.5万亿元（YoY +11%） |
| 十五五可再生能源投资 | 超5万亿元 |
| 2030年可再生能源装机目标 | 35亿千瓦 |
| 2030年风光装机占比 | 超50% |
| 核电运行装机 | 全球第一 |
| 生物质能装机 | 连续7年全球第一 |
| A股综合影响评分 | 72/100（长期偏多） |

### 5.3 火电板块的估值重估风险

## 十、风险提示

### 10.1 上行风险

1. **十五五规划超预期**：若十五五可再生能源装机目标超35亿千瓦，投资超5万亿，板块将迎来估值修复行情。
2. **光伏产能出清加速**：若硅料价格跌破成本线，落后产能加速退出，头部企业盈利有望提前见底。
3. **核电核准加速**：若每年核准8-10台机组，核电产业链将迎来确定性增长。
4. **储能成本持续下降**：若储能系统成本降至0.5元/Wh以下，光储一体化经济性将大幅提升。

### 10.2 下行风险

1. **光伏产能过剩持续**：若组件价格战加剧，头部企业可能出现亏损，板块估值进一步下移。
2. **电网消纳瓶颈**：风光装机占比过高可能导致弃风弃光率上升，影响运营商盈利。
3. **电价市场化改革**：若电价波动加大，新能源运营商收益不确定性增加。
4. **美联储加息影响**：若美联储重启加息，高估值成长板块（新能源设备）估值进一步承压。
5. **政策执行不及预期**：若十五五规划目标下调或执行进度滞后，市场预期落空。
