# 运营商Token经营深度解码：抢AI时代的计费权，从卖额度走向卖承诺

## 摘要

三大运营商集体入局Token经营——中国移动成立集团级Token办公室做平台聚合、中国电信把Token做成9.9元一千万Token的标准化消费品、中国联通锚定产业场景推出元珠计量计费体系。市场叙事是"运营商终于有了新的收入曲线"，但本报告核心判断：**这场生意的真相，是它们在抢AI时代的计费权。**

回顾通信史，运营商从未在任何一次技术竞赛里赢过，但它一直赢着一件事——**它是那个出账单的人**。短信、流量、增值业务，它收的从来不只是过路费，还有把一切数字消费装进自己信封的权力。Token经营的本质，是把AI账单也装进同一个信封。但这条路埋着一个致命的错配：**Token被刻意包装成流量，让人联想到按量付费的合理性，可流量的边际成本递减到近乎零，Token的边际成本却是恒定的——它背后是GPU、电力和折旧。**

### 六大核心观点

1. **Token是一个尚未被定义的商品**：商品定价前提是可比较性，一升水、一度电、一GB流量可互换。而100万Token跑小模型和跑顶级大模型能力天差地别、不同厂商统计口径不一致——等价于卖一升液体但没说是水还是油。**每百万Token价格是一把残缺的尺子：计量了数量却没计量质量，算出成本却算不出价值。卖一个还没被定义的单位，是这场生意最大的风险——不是竞争风险，是地基风险。**
2. **运营商真正要抢的不是Token收入，是计费权**：三家都不是词元完全自主生产者，底层模型大多来自外部。它们争夺的是AI服务的调度权、入口权、最关键的计费结算权。通信史铁律：运营商核心资产从来不是技术，是收费通道。**如果AI时代的消费不能变成运营商账单上的一行，运营商就真的被彻底管道化了——这不是新业务，是生存动作。**
3. **成本结构的致命错配：Token被包装成流量**：流量的边际成本几乎可以忽略，价格战打到极低仍有利润；Token每卖出一份就要真实消耗对应算力、电力和折旧，边际成本不会归零——这不是软件复制逻辑，是重资产产出逻辑。**用一张更贵的资产负债表，去换一张可能亏损的账单收入表。** 价格战从三个月前三到五元砸到一元，不是竞争激烈，是定价的参照系从一开始就选错了。
4. **这是一场伪价格战，国家标准是信任工具**：真正能打价格战的商品必须高度同质，Token之间并不同质。用不同的东西打价格战，结果不是优胜劣汰，而是劣币驱逐良币——用户无法判断一元报价背后的模型质量，便宜的赢了但解决不了问题，整个品类失去信用。**标准在这里不是效率工具，是信任工具，让市场在信息不对称的条件下不至于崩塌。**
5. **真商品不是Token，是SLA**：规定时延、准确率、可用性条件下完成任务——这个东西可比较、可定价，带着明确的承诺。运营商是极少数能为服务等级背书的主体：全国算网一体、遍布各地的运维、政企信用、结算合规。**当市场从卖额度走向卖承诺，比拼的就不再是模型参数，而是履约能力。**
6. **一个不那么悲观的判断：AI比移动互联网更接近运营商的地盘**：移动互联网价值几乎全部发生在软件和应用层，离运营商资产很远；AI的价值有很大一部分发生在算力、网络、边缘节点和电力上——这些恰恰是运营商的地盘。但边界清晰：运营商拿到调度、交付、计费、渠道（计费权和政企渠道含金量最高），拿不到模型能力（定价权最高的部分）——**站在价值链的正确位置，但站在了低毛利段。**

## 第二章 Token是一个尚未被定义的商品

### 2.1 商品的定价前提是可比较性

| 商品 | 可互换性 |
|------|----------|
| 一升水 | 同品类内可互换 |
| 一度电 | 同品类内可互换 |
| 一GB流量 | 同品类内可互换 |
| 100万Token | **不可互换（没说清是什么液体）** |

### 2.2 Token不可比较的三个层面

| 层面 | 问题 |
|------|------|
| 模型能力 | 跑小模型vs顶级大模型，能力天差地别 |
| 统计口径 | 不同厂商Token统计口径不一致 |
| 价值度量 | 计量数量不计量质量，算出成本算不出价值 |

### 2.3 残缺尺子的代价

| 用户视角 | 现实落差 |
|----------|----------|
| 用户买的是 | 解决业务问题 |
| 拿到手的是 | Token数字额度 |
| 中间的落差 | 没有任何制度性安排去填补 |

> **卖一个还没有被定义的单位，这就是这场生意最大的风险。不是竞争风险，是地基风险。计量标准正在制定，但国家标准只能解决怎么数，解决不了值不值。**

## 第三章 三大运营商路径拆解：打法不同，动机高度一致

### 3.1 三家的差异化路径

| 运营商 | 打法 | 路径特征 |
|--------|------|----------|
| 中国移动 | 集团级Token办公室，平台聚合 | 不执着自研大模型，做AI能力超级分发渠道 |
| 中国电信 | Token标准化消费品（9.9元/千万Token个人版、299.9元/月1.5亿Token企业版） | 酷似当年流量套餐 |
| 中国联通 | 元珠计量计费体系，锚定产业场景 | 卖整套行业智能服务 |

### 3.2 共同点：都不是词元的完全自主生产者

| 争夺对象 | 说明 |
|----------|------|
| 调度权 | AI服务的分发调度 |
| 入口权 | 用户入口 |
| **计费结算权** | 最关键的争夺 |
| 模型研发权 | 不在争夺范围（底层模型大多来自外部） |

> **三家本质上都不是词元的完全自主生产者——底层模型大多来自外部。所以它们争夺的，不是模型研发权，而是AI服务的调度权、入口权，以及最关键的计费结算权。**

## 第四章 成本结构的致命错配：Token被包装成流量

### 4.1 Token这个词被选中不是偶然

Token让人立刻联想到流量，而流量是所有习惯了按量付费、价格持续下降的东西。这个类比在心理上极大降低了市场教育成本。

### 4.2 流量与Token的成本结构完全相反

| 维度 | 流量 | Token |
|------|------|-------|
| 计量对象 | 传输了多少数据 | AI产出了多少智能计算 |
| 边际成本 | 持续下降，趋近于零 | 恒定，甚至随负载上升 |
| 成本构成 | 网络折旧，规模效应极强 | GPU、电力、机房，刚性消耗 |
| 定价趋势 | 长期单边下行 | 表面下行，实则逼近成本线 |
| 商业逻辑 | 软件复制逻辑 | **重资产产出逻辑** |

### 4.3 真实姿态：用更贵的资产负债表换可能亏损的账单收入表

| 环节 | 现实 |
|------|------|
| 要卖Token | 就得买算力、付电费、建机房 |
| 卖出去的每一份 | 都在真实消耗 |
| 用户心理预期 | 持续施压价格下行 |
| 成本结构 | 不允许（刚性消耗） |
| 价格战结果 | 三个月从3-5元砸到1元 |

> **把恒定成本的东西包装成递减成本的东西来卖，价格战打到所有人都不赚钱。当前价格战砸到一元的根本原因：不是竞争激烈，是定价的参照系从一开始就选错了。**

## 第五章 伪价格战：国家标准真正的意义

### 5.1 真价格战的前提是商品同质

| 商品 | 同质性 | 价格战结果 |
|------|:---:|------------|
| 流量 | 高度同质 | 出清市场、留下效率最高者 |
| 电力 | 高度同质 | 出清市场 |
| Token | **不同质** | 不是优胜劣汰，而是劣币驱逐良币 |

### 5.2 Token不同质的三个证据

| 证据 | 说明 |
|------|------|
| 完成任务消耗量 | 不同模型完成同一任务消耗Token差距巨大 |
| 能力差距 | 不同模型能力差距更大 |
| 信息不对称 | 用户看到一元报价无法判断背后模型与质量 |

### 5.3 劣币驱逐良币的连锁反应

| 环节 | 后果 |
|------|------|
| 便宜者赢 | 用户无法判断质量，便宜的赢了 |
| 便宜Token | 解决不了问题 |
| 用户流失 | 对整个Token市场失去信任 |
| 最坏结果 | 不是一家企业输掉竞争，是整个品类失去信用 |

> **标准在这里不是效率工具，是信任工具。它的价值不是让计量更统一，而是让市场在信息不对称的条件下不至于崩塌。没有统一的计量框架，这个市场连价格信号都无法正常形成。**

## 第六章 真商品不是Token，是SLA

### 6.1 什么是真正可交易的AI商品

| 维度 | Token额度 | SLA（服务等级承诺） |
|------|-----------|---------------------|
| 计量对象 | 数字额度 | 规定时延/准确率/可用性下完成任务 |
| 可比较性 | 无 | 可比较 |
| 可定价性 | 残缺 | 可定价（带明确承诺） |
| 商业本质 | 卖额度 | 卖承诺 |

### 6.2 运营商是最被低估的SLA背书主体

| 背书资产 | 说明 | 云厂商能否复制 |
|----------|------|:---:|
| 全国算网一体基础设施 | 覆盖全国的算力网络 | 难 |
| 运维体系 | 遍布各地 | 难 |
| 政企信用 | 多年积累 | 难 |
| 结算与合规能力 | 成熟 | 难 |

> **当市场从卖额度走向卖承诺，比拼的就不再是模型参数，而是履约能力。**

### 6.3 产业演进三阶段

| 阶段 | 形态 | 特征 |
|------|------|------|
| 当前 | 按数量计费、套餐化售卖 | 教育市场 |
| 中期 | 叠加质量约束，区分有效与无效词元 | 部分场景按任务效果付费 |
| 远期 | Token演变成AI通用计量媒介 | 必须配套质量、可信与安全规范 |

> **胜负手从来不在能卖出多少额度，而在能不能把计量单位升级成服务承诺。**

## 第七章 一个不那么悲观的判断：AI比移动互联网更接近运营商的地盘

### 7.1 物理层面的关键差异

| 时代 | 价值发生地 | 与运营商资产的距离 |
|------|------------|:---:|
| 移动互联网 | 软件和应用层 | 很远（眼睁睁看价值被平台拿走） |
| AI时代 | 算力、网络、边缘节点、电力 | 很近（正是运营商地盘） |

### 7.2 AI基础设施的物理形态更接近运营商核心资产

| 环节 | 现实约束 |
|------|----------|
| 推理 | 必须跑在机房里 |
| 电力 | 必须消耗 |
| 网络调度 | 必须通过 |
| 政企合规 | 必须满足 |

大模型再强，推理要跑在机房里、消耗电力、通过网络调度、满足政企合规要求。**AI基础设施的物理形态，比App更接近运营商的核心资产。**

### 7.3 价值链位置的边界

| 环节 | 含金量 | 运营商能否拿到 |
|------|:---:|:---:|
| 计费权 | 最高 | 能 |
| 政企渠道 | 最高 | 能 |
| 调度/交付/渠道 | 中 | 能 |
| 模型能力 | 最高 | **不能（产业链定价权最高部分）** |

> **它站在价值链的正确位置，但站在了价值链的低毛利段。模型能力是当前产业链上定价权最高的部分，运营商拿不到；它拿到的是调度、交付、计费、渠道——其中计费权和政企渠道含金量最高，模型能力含金量最低。**

## 第八章 三个最锋利的判断

### 8.1 判断一：Token定价问题不是价格高低，是计量单位尚未成立

| 含义 | 推论 |
|------|------|
| 计量单位尚未成立 | 产业早期形态必然混乱 |
| 不同质商品之间比价 | 市场无法出清 |
| 国家标准先行 | 建立最低限度信任 |
| 收入规模乐观预测 | 都建立在流沙上 |
| 成熟度观察指标 | 看标准落地进度，比看套餐价格更有意义 |

### 8.2 判断二：运营商真正的护城河是计费权与履约能力，不是Token本身

| 事实 | 结论 |
|------|------|
| 模型能力不在手里 | Token额度不稀缺 |
| 出账单的权力 | 稀缺 |
| 为服务等级背书的能力 | 稀缺 |
| 战略重心 | 从卖额度转向卖承诺——谁先把SLA做成商品，谁才真正掌握AI时代的定价权 |

### 8.3 判断三：不要用流量业务的成功路径去推演Token业务

| 维度 | 流量 | Token |
|------|------|-------|
| 成本 | 趋近于零 | 刚性 |
| 促销 | 可无限促销 | 每促销一次真实烧掉一次算力 |
| 用流量打法结果 | —— | 收入增长、利润恶化 |

> **运营商最该警惕的，不是错过这个市场，是用错误的成本模型冲进去。**

## 第九章 认知误区与产业链推演

### 9.1 三个必须避开的误区

| 误区 | 真相 |
|------|------|
| 把Token当AI流量，复刻流量成功路径 | 流量边际成本持续下降，Token背后是GPU和电力刚性消耗，成本结构不支持同一套打法 |
| 以为掌握Token就掌握AI产业链主导权 | 运营商做分发与交付，底层模型能力不在自己手里；模型厂商涨价或迭代，运营商立刻受制于上游。**优势在渠道、网络和计费，不在算法** |
| 以为Token产业爆发所有算力项目都受益 | 未来一定分化：能稳定产出低成本有效词元的项目盈利；只堆硬件、利用率低、产出无效Token的智算中心持续亏损 |

### 9.2 算力供给的现实约束

| 指标 | 数值 | 含义 |
|------|:----:|------|
| 全国智能算力规模 | 2185 EFLOPS | 硬件供给不再是瓶颈 |
| 上架率 | 71.4% | 利用率待提升 |
| 核心考核指标 | 算力利用率与单位有效词元成本 | 替代硬件规模 |

### 9.3 产业链分工定型

| 环节 | 角色 | 核心考核 | 代表玩家 |
|------|------|----------|----------|
| 上游 | 词元工厂（生产） | 单位有效词元成本与算力利用率 | 云厂商、地方智算中心、部分央企 |
| 中游 | 聚合、调度、计费、分发、行业落地 | 全国算网、十亿级用户、成熟计费 | 运营商与云服务商（短板：模型自研） |
| 下游 | 把Token转化成业务价值 | 行业场景落地 | 模型、Agent与行业应用厂商 |

> **整个产业最该记住的一句话：算力不等于词元，硬件不等于商业价值。大量智算中心硬件堆得很大，产出的有效词元却很少，商业回报极差——这正是从比拼算力规模转向比拼有效词元产出的现实背景。**

## 第十一章 风险评估与核心结论

### 11.1 风险监控

| 风险类型 | 监控指标 | 应对 |
|----------|----------|------|
| 计量标准落地进度 | 国家标准出台节奏 | 决定产业成熟度 |
| Token价格战 | 通用Token价格走势 | 逼近成本线即恶化 |
| 运营商模型受制上游 | 模型厂商定价与迭代 | 跟踪议价能力 |
| 智算中心分化 | 算力利用率/有效词元成本 | 回避低利用率标的 |
| SLA商品化进度 | 谁先把SLA做成商品 | 定价权归属 |

### 11.2 核心结论与操作要点

1. **真相是抢计费权**：运营商从未赢过技术竞赛但一直赢着账单；Token经营是把AI账单装进运营商信封的生存动作，不是单纯新收入曲线。
2. **Token尚未被定义**：100万Token没说清是什么液体；每百万Token价格是计量数量不计量质量的残缺尺子；卖未定义的单位是地基风险。
3. **成本结构致命错配**：流量边际成本趋近零、Token边际成本恒定；把恒定成本当递减成本卖，价格战必然打到所有人不赚钱；用更贵的资产负债表换可能亏损的账单收入表。
4. **伪价格战与国家标准**：不同质商品打价格战是劣币驱逐良币、整个品类失去信用；国家标准不是效率工具是信任工具。
5. **真商品是SLA**：运营商是极少数能为服务等级背书的主体；从卖额度走向卖承诺，谁先把SLA做成商品谁掌握定价权。
6. **AI更接近运营商地盘**：算力、网络、边缘、电力恰是运营商核心资产；但模型能力（定价权最高部分）拿不到——站在价值链正确位置但低毛利段。
7. **分化与考核**：算力不等于词元、硬件不等于商业价值；2185 EFLOPS、上架率71.4%下，算力利用率与单位有效词元成本是真正考核指标；回避只堆硬件的智算中心。
8. **A股配置**：做多三大运营商/云服务商/高利用率智算中心/模型Agent，回避低利用率智算中心与硬件过剩环节。

> **一句话提炼：Token经济崛起标志着AI产业从训练大模型走向大规模推理服务落地，三大运营商入局本质是对抗管道化的战略转型——从比特的传输者升级为智能服务的分发运营商。未来胜负不在于卖出多少词元额度，而在于三件事：能不能稳定供给高质量有效词元、能不能真正落到行业场景、能不能从按数量计费升级到按业务价值交付。客户最终购买的从来不是Token这个数字，而是AI解决实际业务问题的能力。谁能先把这件说不清楚的事说清楚，谁就拿到了定价权。**
