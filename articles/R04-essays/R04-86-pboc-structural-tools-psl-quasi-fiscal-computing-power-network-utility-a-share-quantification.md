# 央行四工具深度解码：算力网进了PSL，AI基建正在公用事业化

## 摘要

把这四项工具单独看，是四件事；放在一起看，是同一件事——**当财政空间受限，央行被迫承担起了一部分准财政的职能。** PSL投的是基建资本金，再贷款补贴的是特定领域信贷，这些本该由财政补贴和产业政策来做的事，现在由货币政策工具来执行。原因很现实：土地收入下行，财政扩张的空间被压缩，而结构性定向投放恰恰是货币工具里最接近财政补贴的形态。

而四项工具里最值得警惕的一个细节，是科创再贷款支持比例从60%提到100%——**补贴给谁，取决于定价权在谁手里。当资金供给充足、需求不足时，这笔补贴未必落到企业身上，很可能变成银行的净息差。** 更深的问题是：这四项工具改善的是资金的成本，不是资金的需求。**弹药充足和有人开枪，是两件事。**

### 六大核心观点

1. **算力网进了PSL：AI基础设施正在公用事业化**：PSL是央行向三家政策性银行投放的中长期抵押资金，期限长、利率低，适配建设周期长、投资规模大、回报周期慢的网络型基础设施。**当一个资产能被这样的资金支持，它的性质就变了——从商业投资品，变成了准公共品。** 算力网被纳入，意味着AI算力不再只是企业的商业投资，它被正式确认为国家现代化基础设施，拿到了政策性长期低成本资金的入口。但反直觉的推演随之而来：**PSL进入算力，短期利好建设者，长期可能是在给算力价格战提供弹药。** 这不是雨露均沾的利好，是一次成本优势的再分配。
2. **科创再贷款100%：补贴的归宿，可能是银行的息差**：总额度提到1.4万亿不是关键，支持比例从60%统一提升到100%才是。旧规则下银行承担40%自有资金和信用风险；新规则下合格贷款本金由央行100%匹配，银行几乎不再占用自身负债规模。主流解读是改善银行服务轻资产科技企业的激励，但这个判断只说了一面。**当央行把银行的资金成本消除掉，而贷款利率仍由市场决定时，补贴的最终归宿取决于定价权在谁手里——如果科创贷款利率没有同步下行，100%的资金匹配就直接变成银行的净息差收入。补贴不会凭空落到终端，它会停在链条上有定价权的那一环。** 判断真实效果不能看投放规模，要看科创企业的实际贷款利率有没有下行。再贷款是激励工具，不承担兜底坏账的责任——坏账是滞后的，用再贷款推动的信贷，本质上是把风险的确认时点从当下推迟到了未来。
3. **这四项工具的真正性质：央行在做准财政**：PSL降息扩围（六张网中长期资本金，替财政提供基建资本金）、科创再贷款（科技与技改信贷，替产业政策补贴特定领域）、支农支小再贷款（民企小微涉农，替财政做定向纾困）、再贴现（流动性传导，支持前三者落地）。三项主力工具的共同点是**定向补贴**——而定向补贴传统上是财政的活儿。现在由央行来做，因为**财政的空间被压缩了**：土地收入不可逆下行，财政扩张的能力和意愿都受约束。**所以这轮适度宽松的真实内涵，是货币政策在被迫承担一部分准财政职能。它不再只管总量的水龙头，还要管水流向哪个池子。** 这也解开了为什么不用全面降准降息——全面降准是普惠的，无法定向；结构性工具可以精确到行业。隔夜逆回购在修利率的管道，这四项工具就是在这条管道上装了一排定向的阀门：一个管价格，一个管流向，组合起来才是完整的框架升级。
4. **PSL的三段历史与必须追问的问题**：2014-2019投向棚改货币化，2022-2023投向保交楼和城中村改造，2026年转向六张网。三个阶段共同点是PSL总是被用来解决财政不愿意或不能够直接出钱的事，但宏观后果完全不同——棚改通过货币化安置直达居民端，推动三四线房价上涨和居民杠杆上升；本轮投向网络型基建不经过居民端，不会带来同样的资产价格效应。**这是好消息：同一个工具，投向不同，宏观后果可以完全不同。市场若用棚改的记忆去理解这一轮PSL，是错误地套用了同一段历史。** 但必须追问：为什么本轮PSL不会推高资产价格？因为它没有最终的付款人。算力网、水网、地下管网的最终现金流来自哪里？**PSL不是凭空创造需求，它是把未来的财政支出提前了。水没有消失，只是被挪到了前面。能产生现金流的网是投资，产生不了的网是负债。**
5. **问题的性质已经变了：不是没钱放，是没人借**：四项工具改善的都是资金成本和可得性，也就是供给端。而当前中国信贷面临的主要矛盾恰恰不在供给端——银行体系流动性充裕，问题在于有效需求不足：企业看不到订单因而不愿扩产，居民收入预期偏弱因而不愿加杠杆。**这是一种典型的资产负债表式的谨慎：不是借不到钱，是不想借钱。** 政策反复强调项目储备的前置性，翻译过来就是：**工具提供弹药，但弹药能不能打出去，要看有没有靶标。** 政策工具箱充裕、政策意愿明确，但工具能改变的是资金的分配，改变不了需求的意愿——前者可以靠制度设计解决，后者只能靠时间、靠收入预期的修复、靠真实订单的回暖。**方向明确，力度可控，但不要把工具发布直接等同于业绩兑现。**
6. **三个最锋利的判断**：第一，算力网进入PSL是AI基建公用事业化的开始，而公用事业化的另一面是价格战——看到PSL支持算力，不能只读成利好，要读成一次成本优势的再分配。第二，科创再贷款从60%到100%，补贴的真实落点要看利率而不是规模——判断这项政策成败的唯一标准，是科创企业实际融资成本有没有降，而不是再贷款投放了多少。第三，这轮宽松的本质是央行在财政受限的条件下承担准财政职能，它的边界也在财政——货币政策能解决分配问题，解决不了需求问题；能提供弹药，提供不了靶标。当政策工具已经足够充裕而实体需求仍然疲弱时，继续加码工具本身的边际效力是递减的，真正的变量在别处。

## 第一章 核心结论：央行被迫承担起了一部分准财政职能

### 1.1 四件工具其实是同一件事

| 工具 | 方向 | 实质 |
|------|------|------|
| PSL降息扩围 | 六张网中长期资本金 | 替财政提供基建资本金 |
| 科创再贷款 | 科技与技改信贷 | 替产业政策补贴特定领域 |
| 支农支小再贷款 | 民企、小微、涉农 | 替财政做定向纾困 |
| 再贴现 | 流动性传导 | 支持前三者的落地 |

### 1.2 为什么是央行在做财政的活

| 原因 | 机制 |
|------|------|
| 土地收入下行 | 财政扩张空间被压缩 |
| 财政能力与意愿受限 | 从卖地转向运营的新模式还在建设期 |
| 结构性定向投放 | 货币工具里最接近财政补贴的形态 |

> **当财政空间受限，央行被迫承担起了一部分准财政的职能。这轮适度宽松的真实内涵，是货币政策在被迫承担一部分准财政职能——它不再只管总量的水龙头，还要管水流向哪个池子。**

### 1.3 为什么不用全面降准降息

| 约束 | 说明 |
|------|------|
| 外部利差与汇率 | 总量宽松受约束 |
| 财政无法定向 | 全面降准是普惠的，无法定向 |
| 结构性工具 | 可以精确到行业 |

> **财政没有能力做定向，货币政策就只好替它做定向。如果说前一次的隔夜逆回购是在修利率的管道，那么这四项工具，就是在这条管道上装了一排定向的阀门。一个管价格，一个管流向，组合起来才是完整的框架升级。**

## 第二章 算力网进了PSL：AI基础设施正在公用事业化

### 2.1 PSL的性质

| 特征 | 内容 |
|------|------|
| 投放对象 | 三家政策性银行 |
| 资金性质 | 中长期抵押资金 |
| 期限 | 长 |
| 利率 | 低 |
| 适配对象 | 建设周期长、投资规模大、回报周期慢的网络型基础设施 |

### 2.2 资产性质的转变

| 转变 | 说明 |
|------|------|
| 从商业投资品 | 到准公共品 |
| 算力网确认 | AI算力是国家现代化基础设施 |
| 政策入口 | 拿到政策性长期低成本资金 |

### 2.3 反直觉的推演：价格战弹药

| 环节 | 机制 |
|------|------|
| 政策性资金成本 | 远低于市场化资金 |
| 拿到PSL的项目 | 天然具备成本优势 |
| 成本优势转化 | 竞争里迅速转化为价格优势 |
| 结果 | 低成本资金建设的产能拉低整个行业算力价格 |

> **PSL进入算力，短期利好建设者，长期可能是在给算力价格战提供弹药。供给端获得补贴的行业，商品化和价格战会来得更快——这跟Token市场正在发生的事，本质是同一个机制。**

### 2.4 投资逻辑的再区分

| 角色 | 影响 |
|------|:---:|
| 拿到政策性资金的建设和运营方 | 受益 |
| 同赛道上成本更高的市场化玩家 | 受损 |

> **这不是雨露均沾的利好，是一次成本优势的再分配。**

## 第三章 科创再贷款100%：补贴的归宿，可能是银行的息差

### 3.1 规则变化的关键

| 维度 | 旧规则 | 新规则 |
|------|--------|--------|
| 额度 | 1.2万亿 | 1.4万亿 |
| 支持比例 | 60% | 100% |
| 银行自有资金 | 承担40% | 几乎不再占用 |
| 信用风险 | 银行承担40%对应风险 | 央行100%匹配资金 |

> **总额度提到1.4万亿不是关键，真正的关键是从60%统一提升到100%。**

### 3.2 主流解读只说了一面

| 主流解读 | 另一面 |
|----------|--------|
| 改善银行服务轻资产科技型企业激励 | 央行消除银行资金成本，贷款利率仍由市场决定 |
| 推动授信逻辑从看抵押物转向看技术前景 | 补贴最终归宿取决于定价权在谁手里 |
| 判断正确 | 只说了一面 |

### 3.3 补贴的归宿：定价权法则

| 情形 | 补贴归宿 |
|------|----------|
| 科创贷款利率同步下行 | 补贴落到企业 |
| 贷款利率未下行 | 100%资金匹配直接变成银行净息差收入 |

> **补贴不会凭空落到终端，它会停在链条上有定价权的那一环。当资金供给充足、而企业的融资需求并不旺盛时，银行的议价能力反而更强，补贴更容易被中间环节吸收。**

### 3.4 判断政策真实效果的标准

| 错误标准 | 正确标准 |
|----------|----------|
| 再贷款投放规模 | 科创企业实际贷款利率有没有下行 |

> **规模是政策的意愿，利率才是政策的落点。**

### 3.5 再贷款的边界：不承担兜底坏账

| 边界 | 含义 |
|------|------|
| 激励工具 | 不承担兜底坏账责任 |
| 资金成本被解决 | 坏账风险仍完全由商业银行承担 |
| 坏账是滞后的 | 投放期可能出现较快量增，风险显现往后推两三年 |

> **用再贷款推动的信贷，本质上是把风险的确认时点，从当下推迟到了未来。**

## 第五章 PSL的三段历史，与一个必须追问的问题

### 5.1 三段历史

| 阶段 | 投向 | 宏观后果 |
|------|------|----------|
| 2014-2019 | 棚改货币化 | 直达居民端，推动三四线房价上涨和居民杠杆上升 |
| 2022-2023 | 保交楼和城中村改造 | 民生纾困 |
| 2026 | 六张网 | 网络型基建，不经过居民端 |

### 5.2 共同点与不同点

| 维度 | 棚改 | 本轮六张网 |
|------|------|-----------|
| 共同点 | 解决财政不愿意或不能直接出钱的事 | 同左 |
| 经过居民端 | 是 | 否 |
| 资产价格效应 | 推升 | 不产生同样效应 |
| 最终付款人 | 购房者接盘 | 没有最终付款人 |

> **这是好消息：同一个工具，投向不同，宏观后果可以完全不同。市场若用棚改的记忆去理解这一轮PSL，是错误地套用了同一段历史。**

### 5.3 必须追问的问题：为什么本轮PSL不会推高资产价格

| 追问 | 回答 |
|------|------|
| 为什么不会推高资产价格 | 因为没有最终的付款人 |
| 算力网/水网/管网现金流来自哪里 | 政府购买服务或使用者付费 |
| 最终依赖 | 仍然是财政和居民 |

> **PSL不是凭空创造需求，它是把未来的财政支出提前了。水没有消失，只是被挪到了前面。**

### 5.4 投资与负债之分

> **能产生现金流的网是投资，产生不了的网是负债。这两个字之差，决定了十年后这张资产负债表的样子。**

## 第六章 问题的性质已经变了：不是没钱放，是没人借

### 6.1 供给端 vs 需求端

| 维度 | 供给端 | 需求端 |
|------|--------|--------|
| 四项工具改善 | 资金成本与可得性 | —— |
| 银行体系现状 | 流动性充裕 | 有效需求不足 |
| 企业行为 | —— | 看不到订单因而不愿扩产 |
| 居民行为 | —— | 收入预期偏弱因而不愿加杠杆 |

### 6.2 资产负债表式谨慎

| 特征 | 含义 |
|------|------|
| 不是借不到钱 | 是不想借钱 |
| 类型 | 资产负债表式的谨慎 |

> **这四项工具的效力，最终取决于有没有人愿意借。弹药充足和有人开枪，是两件事。**

### 6.3 项目储备的前置性

| 政策表述 | 翻译 |
|----------|------|
| 反复强调项目储备的前置性 | 工具提供弹药，弹药能不能打出去要看有没有靶标 |
| PSL扩围不等于立刻天量投放 | 额度要看项目储备 |
| 优质项目不足 | 工具规模难以充分释放 |

### 6.4 政策能力的边界

| 能力 | 边界 |
|------|------|
| 改变资金分配 | 可以靠制度设计解决 |
| 改变需求意愿 | 只能靠时间、收入预期修复、真实订单回暖 |

> **政策工具箱是充裕的，政策意愿也是明确的，但工具能改变的是资金的分配，改变不了需求的意愿。看这四项政策，正确的态度是：方向明确，力度可控，但不要把工具发布直接等同于业绩兑现。**

## 第七章 三个最锋利的判断

### 7.1 判断一：算力网进PSL是AI基建公用事业化的开始，公用事业化的另一面是价格战

| 维度 | 内容 |
|------|------|
| 正面 | AI基建确认公用事业化 |
| 另一面 | 政策性低成本资金把算力价格拉向更低位置 |
| 受益 | 拿到资金的建设运营方 |
| 受损 | 同赛道成本更高的市场化玩家 |
| 正确解读 | 成本优势的再分配，而非简单利好 |

### 7.2 判断二：科创再贷款从60%到100%，补贴的真实落点要看利率而不是规模

| 维度 | 内容 |
|------|------|
| 资金成本被央行消除 | 贷款利率仍由市场决定 |
| 可能结果 | 补贴停在银行这一环变成息差 |
| 判断成败的唯一标准 | 科创企业实际融资成本有没有降 |
| 错误标准 | 再贷款投放了多少 |

### 7.3 判断三：这轮宽松的本质是央行在财政受限条件下承担准财政职能，边界也在财政

| 维度 | 内容 |
|------|------|
| 货币政策能解决 | 分配问题 |
| 解决不了 | 需求问题 |
| 能提供 | 弹药 |
| 提供不了 | 靶标 |
| 结论 | 工具边际效力递减，真正变量在别处 |

> **当政策工具已经足够充裕而实体需求仍然疲弱时，继续加码工具本身的边际效力是递减的——真正的变量在别处。**

## 第八章 四大误区与推演清单

### 8.1 四个必须避开的误区

## 第十章 风险评估与核心结论

### 10.1 风险监控

| 风险类型 | 监控指标 | 应对 |
|----------|----------|------|
| 政策兑现慢 | PSL月度投放量 | 弹药≠开枪 |
| 补贴被中间吸收 | 科创贷款利率是否下行 | 看利率不看规模 |
| 算力价格战 | 算力价格走势 | 区分资金获得者/市场化玩家 |
| 坏账滞后 | 再贷款风险显现（2-3年） | 风险确认时点推迟 |
| 项目储备不足 | 六张网开工落地 | 靶标够不够 |
| 财政空间 | 财政政策是否打开 | 真正变量在财政 |

### 10.2 核心结论与操作要点

1. **央行承担准财政职能**：财政空间受限（土地收入下行），结构性定向投放成为货币工具里最接近财政补贴的形态；隔夜逆回购修利率管道+四工具装定向阀门=完整框架升级。
2. **算力网公用事业化**：AI基建从商业投资品变准公共品；但公用事业化的另一面是价格战——低成本政策资金产能拉低行业价格，供给端获得补贴的行业商品化更快；受益的是资金获得者，受损的是市场化玩家。
3. **科创再贷款100%**：补贴归宿取决于定价权；资金供给充足、需求不足时补贴很可能变成银行净息差；判断成败唯一标准是科创企业实际融资成本有没有降；再贷款不兜底坏账，风险确认时点被推迟。
4. **PSL三段历史**：棚改直达居民端推升房价，本轮投向网络型基建不经过居民端；用棚改记忆理解本轮PSL是错误套用；本轮没有最终付款人，PSL是把未来财政支出提前了；能产生现金流的网是投资，产生不了的网是负债。
5. **不是没钱放是没人借**：资产负债表式谨慎——不是借不到钱是不想借钱；工具提供弹药，弹药能不能打出去要看有没有靶标；工具改变资金分配，改变不了需求意愿。
6. **A股配置**：做多拿到政策性资金的算力网建设运营方/新型电网通信网/传统基建国企，结构精选硬科技设备更新与银行，观察民营小微，回避纯市场化算力玩家；跟踪PSL月度投放、科创贷款利率、六张网开工落地三大指标。

> **一句话提炼：这套四件套，是适度宽松背景下一次典型的货币政策工具箱升级。它的核心逻辑不是放水，是改道——PSL服务六张网的新老基建，科创再贷款从60%提到100%撬动科技产业，支农支小再贷款托底微观主体。货币宽松的力量不再追求雨露均沾，而是精准向基建新质生产力、科技创新、民营小微三个方向定向输送。但要记住两件事：第一，这四项工具改善的是资金供给的条件，而当前的核心矛盾在需求端——钱已经不是问题，愿意借钱的人才是。第二，政策工具越用越精细，越说明它要替代的功能本该在别处——当央行开始替财政做定向补贴时，真正需要被观察的，不是央行的动作，是财政的空间什么时候打开。在那之前，定向的阀门会继续拧紧，而水能不能流到该去的地方，取决于池子里有没有人接。**
